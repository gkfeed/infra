- STATUS: PENDING

## Цель

Создать безопасный dry-run каркас временного импортёра из SQLite в PostgreSQL,
пока без переноса данных.

## План

- [ ] Создать изолированный Python CLI в `legacy-import/` с отдельными
      зависимостями.
- [ ] Принимать пути и URL только аргументами командной строки или через env.
- [ ] Открывать SQLite только для чтения.
- [ ] Подключаться к PostgreSQL и отказываться от работы, если целевые доменные
      таблицы непусты.
- [ ] В dry-run выводить только безопасные counts и schema summary.
- [ ] Никогда не выводить credentials или содержимое записей.
- [ ] Не переносить данные в этой задаче.

## Готово, когда

Dry-run безопасно показывает counts и schema summary, не раскрывая credentials
или содержимое записей.
